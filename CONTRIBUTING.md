# Współtworzenie

Projekt ma charakter edukacyjny. Zmiany powinny być małe, zrozumiałe i zgodne
z istniejącą architekturą.

- Dodaj lub zaktualizuj dokumentację, gdy zmienia się opisywane zachowanie.
- Dodaj testy adekwatne do zmienianego kodu i uruchom właściwy zestaw testów.
- Aktualizuj [PROJECT_STATE.md](PROJECT_STATE.md) przy zmianie etapu lub
	najbliższego kroku, nie przy każdej zmianie.
- Stosuj format commitów opisany w [PROJECT_WORKFLOW.md](docs/PROJECT_WORKFLOW.md).
- Szczegółowy cykl pracy opisuje [PROJECT_WORKFLOW.md](docs/PROJECT_WORKFLOW.md).
