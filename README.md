# Report Studio

## Cele projektu

Projekt realizowany w celach edukacyjnych.

Założenia:

- nauka FastAPI
- nauka architektury aplikacji
- nauka JavaScript
- budowa wizualnego projektanta raportów
- pełna dokumentacja procesu wytwarzania oprogramowania

Technologie:

- FastAPI
- Vanilla JavaScript
- Konva.js
- GSAP
- MS SQL Server
