# Vision

## Nazwa projektu

Report Studio

## Cel

Stworzenie nowoczesnego wizualnego projektanta raportów
działającego w przeglądarce internetowej.

## Inspiracje

- Crystal Reports
- FastReport
- JasperReports
- Power BI Report Builder

## Główne założenia

- pełna dokumentacja
- rozwój etapowy
- edukacyjny charakter projektu
- architektura modułowa
- możliwość pracy z wieloma źródłami danych

## Źródła danych objęte wizją

- Microsoft SQL Server
- CSV
- Excel
- JSON
- STDIN
- Windows Named Pipe
- Unix FIFO

## Docelowe formaty eksportu

- HTML
- PDF
- Excel
- CSV
- XML
