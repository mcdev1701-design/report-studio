# ADR-001

## Tytuł

Filozofia projektu

## Status

Accepted

## Decyzja

Projekt rozwijany jest przede wszystkim
w celach edukacyjnych.

Każdy element projektu powinien być:

- zaprojektowany,
- udokumentowany,
- zaimplementowany,
- przetestowany.

## Uzasadnienie

Celem jest nauka technologii poprzez
budowę kompletnego produktu klasy enterprise.

## Konsekwencje

Rozwój projektu będzie wolniejszy,
ale każda część systemu będzie dobrze zrozumiana.
