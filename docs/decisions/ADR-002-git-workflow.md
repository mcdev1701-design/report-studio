# ADR-002

## Tytuł

Strategia Git

## Status

Accepted

## Decyzja

Projekt wykorzystuje model:

main
develop
feature/*

## Zasady

main
- stabilne wersje

develop
- bieżący rozwój

feature/*
- pojedyncze funkcjonalności

## Wersjonowanie

Do oznaczania wydań używane są tagi.

Przykład:

v0.1.0
v0.2.0
v1.0.0
